===== PAGE 2 =====
Qu’est-ce qu’un système de
fichiers ?
1/2
Définition :

Un système de fichiers (File System) est une méthode
d’organisation et de gestion des données sur un support de
stockage (disque dur, SSD, clé USB, etc.).

Il permet au système d’exploitation de stocker, lire, modifier et
supprimer des fichiers.

===== PAGE 3 =====
Qu’est-ce qu’un système de
fichiers ?
2/2
Fonctions principales :

Organisation hiérarchique des fichiers et répertoires.

Gestion des métadonnées (taille, propriétaire, permissions, date…).

Contrôle des accès aux ressources (droits utilisateurs).

Allocation et libération d’espace disque.

Fiabilité et tolérance aux pannes (journalisation, vérification
d’intégrité).

===== PAGE 5 =====
Utilisation typique

NTFS est le plus sécurisé sous Windows, tandis qu’ext4 domine sur
Linux.
Parfait pour les disques internes windows, supporte les droitss d’accées utilisateurs, la compression et
la journalisation

FAT32 reste le plus compatible, mais limité à 4 Go par fichier.
Parfait pour les disques internes windows, supporte les droitss d’accées utilisateurs, la compression et
la journalisation

exFat Idéal pour les clés USB ou disques externes compatibles
Windows/macOS/Linux.
Recommandé pour transférer de gros fichiers multimédias, moins sûr(pas de journalisation ni
permissions avancées).

===== PAGE 6 =====
Utilisation typique

Ext4 Système par défaut de la plupart des distributions Linux
(Ubuntu, Debian…).
Convient aux serveurs et postes Linux pour sa stabilité et sa performance.

XFS Utilisé sur les serveurs Linux professionnels.
Très efficace pour les gros volumes de données ou les fichiers volumineux.

Btrfs Choisi pour les systèmes modernes cherchant la résilience
et la gestion avancée (snapshots, compression…).
À réserver aux administrateurs expérimentés.

APFS Utilisé exclusivement sur macOS et iOS.
Optimisé pour les SSD, très rapide et sécurisé.

===== PAGE 10 =====
Explication:
EXT3 (Third Extended File System)
-
Ancien standard de Linux. Qui a Introduit la journalisation, ce qui permet une restauration
facile
EXT4 (Fourth Extended File System)
-
Par défaut sur la plupart des distributions Linux modernes.
-
Meilleure performance pour les gros fichiers et partitions
HPFS (High Performance File System)
-
Développé par IBM pour OS/2. Gestion efficace de gros fichiers. Peu utilisé aujourd’hui
VFAT (Virtual File Allocation Table)
-
Version améliorée de FAT16/FAT32, introduite avec Windows 95.
Idéal pour les clés USB et disques externes.
FreeBSD UFS (Unix File System)
-
Stable, sécurisé et conçu pour les serveurs.
-
Robuste Gestion fine des droits d’accès et des quotas utilisateurs.

===== PAGE 18 =====
Navigation dans le système de
fichiers

/mnt : point de montage temporaire pour des
systèmes de fichiers externes ou réseaux.

/media : montage automatique de périphériques
amovibles comme (USB, CD, etc.)

/proc et /sys : systèmes de fichiers virtuels exposant
des informations du noyau et des processus

/root : répertoire personnel de l’administrateur

===== PAGE 19 =====

/mnt est utilisé comme point de montage temporaire pour
tout disque ou partition que l’on souhaite accèder
ponctuellement

Cela peut être un disque interne secondaire, une partition
interne, ou un disque externe

Exemple pour un disque interne secondaire :
sudo mount /dev/sdb1 /mnt

Exemple pour un disque externe :
sudo mount /dev/sdc1 /mnt
Le répertoire /mnt

===== PAGE 26 =====
Montage d’un système de fichiers
1/6

Principe du montage

Un système de fichiers doit être monté avant
utilisation

Le montage connecte une partition à un répertoire
(point de montage)
Exemple : /dev/sdb1 →/mnt/usb

===== PAGE 27 =====
Montage d’un système de fichiers
2/6

Commandes de montage

mount [options] /dev/sdX /mnt/dossier

umount /mnt/dossier

Vérifier le montage : df -h, lsblk, mount | grep /mnt
Les utilisateurs non-root doivent avoir les droits
nécessaires

===== PAGE 28 =====
Le fichier /etc/fstab 3/6

Fichier de configuration pour les montages
automatiques

Format :

/dev/sda1 /boot ext4 defaults 0 2

UUID=xxxx /data ext4 defaults 0 0

Avantage : montage automatique au démarrage
