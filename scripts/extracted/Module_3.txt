===== PAGE 16 =====
3. Mémoire virtuelle et swap

Objectif:
Comprendre comment Linux utilise la mémoire virtuelle pour
compléter la RAM physique et gérer les pages mémoire inactives.

Pourquoi utiliser la mémoire virtuelle ?
-
Permet au système de continuer à fonctionner lorsque la RAM
est saturée.
-
Permet la mise en veille ou hibernation sur certains systèmes.
-
Facilite la gestion multitâche et l’allocation dynamique de
mémoire.

===== PAGE 17 =====
3. Mémoire virtuelle et swap

Concepts Clés
Élément
Description
Mémoire virtuelle
Extension de la RAM sur le disque. Permet à Linux de gérer plus de mémoire que la
RAM physique disponible.
Swap
Zone spécifique (partition ou fichier) utilisée pour stocker les pages mémoire
inactives afin de libérer de la RAM pour les processus actifs.
Partition swap
Ex. /dev/sda5 : espace disque réservé exclusivement pour le swap.
Fichier swap
Ex. /swapfile : fichier standard créé sur une partition existante pour le swap.

===== PAGE 19 =====
3. Mémoire virtuelle et swap

Créer un fichier swap :
-
sudo fallocate -l 2G /swapfile
# crée un fichier swap de 2 Go
-
Sudo chmod 600 /swapfile
# permissions strictes
-
sudo mkswap /swapfile
# formate le fichier en swap
-
sudo swapon /swapfile
# active le swap

Rendre le swap permanent (ajouter à /etc/fstab)
-
/swafile none swap sw 0 0

===== PAGE 20 =====
Paramétrage du swappiness

Objectif:
Contrôler la fréquence d’utilisation du swap par le noyau Linux afin
d’optimiser les performances de la mémoire

Concept clé : vm.swappiness
Valeur
Comportement
0
Évite au maximum l’utilisation du swap →privilégie la RAM.
60
Valeur par défaut sur la plupart des distributions Linux →équilibre RAM /
swap.
100
Utilisation agressive du swap →le noyau déplace plus tôt les pages
inactives sur disque.

===== PAGE 21 =====
Paramétrage du swappiness

Vérifier le swappiness actuel :
cat /proc/sys/vm/swappiness
-
Affiche un nombre souvent 60 par défaut
-
Permet de savoir à quel point le système utilise le swap

Modifier temporairement le swappiness
Sudo sysctl vm.swappiness=20
-
Change la valeur immédiatement jusqu’au prochain redémarrage
-
Exemple: 20 →préfère fortement la RAM, swap seulement si nécessaire.

Modifier définitivement :
Sudo nano /etc/sysctl.conf
-
Ajouter la ligne vm.swappiness=20
-
Appliquer les changement sans redémarrer : sudo sysctl -p
lecture / kernel runtime
Modification Temps réel
Sauvegarde pour les
démarrage futurs

===== PAGE 23 =====
4. 1 Commande Crontab

sudo crontab -e
0 2 * * 0 /sbin/fsck -AR –y
-
0 2 * * 0 : exécuter à 2h du matin chaque dimanche
-
minute heure jour_du_mois mois jour_de_la_semaine
-
/sbin/ →dossier où se trouvent les commandes systèmes essentielles
-
Fsck →File System Check, c’est-à-dire l’outil de vérification des systèmes de
fichiers Linux.
-
A →Vérifie tous les systèmes de fichiers listés dans /etc/fstab
-
R →Ignore la racine / pour éviter de bloquer le système
-
Y →répond automatiquement oui a toutes les corrections

===== PAGE 24 =====
4. 2 Commande logrotate

Fichier global : /etc/logrotate/conf
-
C’est la configuration principale de logrotate pour tous les logs du système

Fichier spécifiques: /etc/logrotate.d/
-
Chaque service(apache, syslog…) peut avoir son propre fichier dans ce dossier

Edition : sudo nano /etc/logrotate.d/syslog
-
Dans nano Ctrl + O puis Ctrl + X
-
Dans vim :wq

Mode Test:
Sudo logrotate –d /etc/logrotate.conf

Forcer la rotation maintenant
Sudo logrotate –f /etc/logrotate.conf

===== PAGE 25 =====
4. 3 Commande tmpwatch

Supprimer automatiquement les fichiers temporaires anciens

Les fichiers temporaires sont souvent stockés dans /tmp, /var/tmp ..

Sans nettoyage, il peuvent s’accumuler et saturer le disque

sudo tmpwatch [options] <durée_en_heures> <répertoire>
-
Durée_en_heures →supprimer les fichiers non modifiés depuis cette durée
-
Répertoire →dossier à nettoyer
-
sudo tmpwatch 24 /tmp

On peut programmer ça avec cron :
-
0 3 * * * /usr/sbin/tmpwatch 24 /tmp
-
Pour nettoyer /tmp tous les jours à 3h du matin
