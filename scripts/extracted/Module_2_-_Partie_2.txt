===== PAGE 2 =====
1. Nommage des médias de
stockage

Types de médias
-
HDD (Hard Disk Drive) →Disque dur classique.
-
SSD(Solid State Drive) →Disque à mémoire flash, plus rapide
-
Clé USB →Périphérique amovible, souvent monté
automatiquement.
-
CD/DVD →Support optique, souvent monté dans /media ou
/mnt/cdrom

Localisation :
-
/dev/sda →premier disque détecté.
-
/dev/sdb1 →première partition du deuxième disque.
-
/dev/sdc →troisième disque (souvent un périphérique USB).

===== PAGE 3 =====
Convention de nommage
Linux

Disques SATA/SCSI:
-
X: lettre identifiant le disque (a, b, c, ..)
-
Exemple: /dev/sda(1er disque), /dev/sdb 2e disque

Disque NVMe(SSD modernes):
-
/dev/nvme0n1px
-
Nvme0n1: premier périphérique NVMe détecté.
-
/dev/nvme0n1p1 →p1, 1ère partition du disque NVMe.

Carte SD
-
/dev/mmcblmXpX
-
Mmcblk0: premiere carte SD détectée
-
Px: numéro de partition

===== PAGE 4 =====
Fichier /etc/fstab

Le fichier /etc/fstab
Role: Fichier de configuration pour les montages
automatiques
comment editer ce fichier

Format :

0: pas de sauvegarde avec dump
1: Sauvegarde activée

Avantage : montage automatique au démarrage

===== PAGE 5 =====

Etapes recommandées (en mode administrateur)
-
Sudo nano /etc/fstab
-
Sudo vim /etc/fstab

Faire une sauvegarde avant modification:
-
Sudo cp /etc/fstab /etc/fstab.backup (Cas de restauration : sudo cp /etc/fstab.backup /etc/fstab)

Ajouter ou modifier la ligne voulue
-
/dev/sdb1 /mnt/data ext defaults 0 0

Tester la validité du fichier avant de redemarrer :
-
Sudo mount –a
Cette commande monte tous les sytèmes définis dans fstab
Si aucune erreur n’apprait, la configuration est correcte

Redemarrer le système
-
Sudo reboot
Astuce : Utiliser sudo blkid pour obtenir UUID : les UUID sont plus fiables que les
/dev/sdX (qui peuvent changer selon l’ordre de branchement)
Comment éditer le fichier /etc/fstab

===== PAGE 18 =====
3. Partitionnement des disques

Le partitionnement du disque consiste à diviser un disque dur
physique en plusieurs partitions logiques.
Chaque partition peut contenir un système de fichiers (FS)
distinct et être utilisée pour un rôle différent.
Type
Description
Exemple
Primaire
Partition principale du disque (max 4 sur
un disque MBR)
/dev/sda1
Étendue
Conteneur permettant de créer des
partitions supplémentaires
/dev/sda2
Logique
Située à l’intérieur d’une partition
étendue
/dev/sda5, /dev/sda6, etc.
MBR (Master Boot Record) et GPT (GUID Partition Table) sont deux méthodes de
partitionnement de disque,

===== PAGE 21 =====
Tables de partition : MBR vs
GPT

MBR : ancien, max 4 primaires, ≤2 To

GPT : moderne, jusqu’à 128 partitions, >2 To

GPT recommandé pour UEFI
UEFI : un remplaçant moderne et plus performant du BIOS traditionnel, qui sert
d'interface entre le matériel et le système d'exploitation d'un ordinateur

Signification
