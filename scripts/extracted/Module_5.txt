===== PAGE 5 =====
Fichier /etc/passwd
C’est un fichier de configuration fondamental dans les systèmes
d'exploitation de type Unix, y compris Linux. Il contient des
informations essentielles sur les comptes d'utilisateurs du système

Format :
nom:x:UID:GID:infoComplementaire:répertoire_perso:shell

Exemple :

etudiant:x:1001:1001:Etudiant:/home/etudiant:/bin/bash

===== PAGE 6 =====
Fichier /etc/shadow

Contrairement au fichier /etc/passwd qui est public, le fichier
/etc/shadow n’est accessible qu’à l’utilisateur root

Contient les mots de passe chiffrés et politiques de sécurité.

Format : nom:motdepasse:lastchg:min:max:warn:inactive:expire
-
Nom d’utilisateur
-
Mot de passe chifré
-
Dernier changement
-
Nbre de jours minimale avant que le mot de passe puisse être changé à nouveau
-
Nbre de jours maximal après lequel le mot de passe doit être changé
-
Période d’avertissement
-
Période d’inactivité
-
Date d’expériration
-
Champ réservé

===== PAGE 7 =====
Fichiers /etc/group et
/etc/gshadow

Les fichiers /etc/group et /etc/gshadow sont des fichiers de
configuration qui gérent les informations relatives aux groupes
d’utilisateurs. alors que /etc/group contient les informations de
base sur les groupes, /etc/gshadw stocke de manière sécurisée les
données sensibles des groupes, comme les mot de passe

===== PAGE 8 =====
/etc/login.defs et
/etc/default/useradd

Ces deux fichiers sont des fichiers de configuration système qui
définissent le comportement par défaut lors de la création de
nouveaux utilisateurs sous Linux.

Le premier contient des paramètres globaux de sécurité et de
gestion des utilisateurs.
-
UID_MIN, UID_MAX, PASS_MAX_DAYS, PASS_MIN_DAYS

Le deuxième contient les paramètres par défaut utilisés par la 
commande useradd.
-
HOME, SHELL( souvent /bin/bash), CREATE_HOME
-
Aussi SKEL qui est un répértoire contenant les fichiers modèles à
copier dans le répértoire personnel /etc/skel

Créé automatiquement avec l’option -m de useradd.

===== PAGE 15 =====
Création de groupes
Un groupe est un ensemble d’utilisateurs qui partagent des droits ou des ressources
communes.

Commande principale
sudo groupadd developpeurs

Renommer le groupe « developpeur » en « dev »
sudo groupmod -n dev developpeurs

Supprimer le groupe
sudo groupdel dev

Ajouter plusieurs utilisateurs à ce groupe:
Sudo usermod –aG projetA alice
Sudo usermod –aG projetA bob

Donner au groupe accès a un dossier:
Sudo chown :projetA /srv/projetA
Sudo chmod 770 /srv/projetA

Gestion des permissions et
ownership

Lecture des permissions
-
Commande ls-l
-
-rw-r--r-- 1 alice dev 1024 Oct 28 12:00 fichier.txt

Modifier les permssions: chmod
-
chmod u+x fichier.txt
# ajoute le droit exécution au propriétaire
-
chmod g-w fichier.txt
# retire le droit écriture au groupe
-
chmod 755 fichier.txt
# rwx pour propriétaire, r-x pour groupe et
autres

Bonnes pratiques :
Fichiers personnels →600
Dossiers partagés →770 ou 775

===== PAGE 22 =====
Gestion des permissions et
ownership

Modifier propriétaire et groupe : chown / chgrp
-

-
sudo chgrp dev fichier.txt
# change le groupe
-
sudo chown alice:dev fichier.txt # change les deux

===== PAGE 25 =====
PAM – Pluggable
Authentication Modules

C’est une infrastructure flexible qui permet aux systèmes
d'exploitation de gérer l'authentification des utilisateurs de
manière centralisée et configurable, sans avoir à modifier le code
des applications

Les administrateurs peuvent personnaliser l’authentification pour
un service en modifiant simplement ses fichiers de configuration
dans le répertoire /etc/pam.d

Automatisation avec scripts
Bash

Création d’utilisateurs depuis CSV
while IFS=, read -r user pwd; do
sudo useradd -m -s /bin/bash "$user"
echo "$user:$pwd" | sudo chpasswd
done < utilisateurs.csv

Script de sauvegarde des comptes
#!/bin/bash
cp /etc/passwd /backup/passwd_$(date +%F).bak
cp /etc/shadow /backup/shadow_$(date +%F).bak
echo "Sauvegarde effectuée $(date)"

===== PAGE 28 =====
Introduction aux quotas disque

Limiter l’espace disque d’un utilisateur ou d’un
groupe

Évite qu’un utilisateur monopolise tout le stockage
Activer la gestion des quotas
sudo quotacheck -cum /home
sudo quotaon /home
Édition et affichage
sudo edquota etudiant
# modifier les quotas
repquota /home
# afficher les rapports
